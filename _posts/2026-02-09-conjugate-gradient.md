### 1. Motivation : 
   
   In the previous writing, we discussed about **Steep Descent**. One of the urgent problems is that reducing factor is linearly dependent its condition number. So we mentioned that we need to change linearly decreasing algorithm as quadratically decreasing one. 

   the motivation of modifying **SD** is utilizing the previous information about $r_k$. Thereby we can calculate the next $r_{k+1}$ with high convergence rate. 

   In order to accomplish what we intend, we return to the term **T-cyclic subspace generated by \alpha** in Linear Algebra. Let $V$ be finite dimensional vector space with $k=\text{dim}(V)$, $\alpha \in V$. we collect vectors generated by $\alpha$, which is $\{g(T)\alpha \ : \ g \in F[x] \ \} = \text{span}(\alpha, A\alpha, A^2\alpha, \cdots, A^{k-1}\alpha)$  

   We set $\alpha = r_0$. Since we prove $\langle r_k, r_{k+1} = 0 \rangle$ $\forall k\ge0$, those $r_0$, $r_1$, .. , $r_i$ are orthogonal. Hence, $\text{span}(r_0, r_1, r_2, \cdots, r_{i})$ consists of orthogonal vectors. By projecting remain residual vector r_{i+1} onto current spanned subspace, the only remain parts of residual vector are the complements of that subspace. "zig-zag" problem is gone through this subspace setting.

### 3. Algorithm & Code : 
   ```matlab

   function x = CG_my(A,b) % A must be SPD
      n = length(b);
      x = zeros(n,1);
      i = 0;
      r = b-A*x;
      p = r;
      delta = r' * r;
      delta_0 = delta;
      epsilon = 1e-13;
      while i < 1000 && delta > epsilon * epsilon * delta_0
         % recursive 
         q = A*p; % r 대신 p 
         alpha = delta / (p' * q); % r 대신 p
         x = x + alpha * p; % r 대신 p 

         if ( mod(i,50) == 0)
            r = b - A*x;
         else
            r = r - alpha * q;
         end

         delta_old = delta; 
         delta = r' * r;
         beta = delta / delta_old; 
         p = r + beta * p;
         i=i+1;
      end
end
   ```
